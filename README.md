# TrashCommand

Server-side Fabric mod for Minecraft 1.21.11 that keeps worlds flagged Hardcore while optionally overriding hardcore restrictions for difficulty/gamemode/commands/gamerules and configurable death behavior.

Generated by **ModForge AI**.

- Minecraft: `1.21.11`
- Loader: Fabric `0.18.4`
- Fabric API: `0.141.4+1.21.11`

## Build

```bash
./gradlew build
```

The compiled `.jar` will be placed in `build/libs/`. GitHub Actions builds it automatically on push and publishes it to Releases.
